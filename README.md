# مولد التقارير الذكي — النسخة المطوّرة

## التشغيل على Windows في VS Code

1. احتفظي بنسخة احتياطية من مشروعك الحالي.
2. انسخي ملفات هذه الحزمة إلى مشروع `smart report generator` مع استبدال الملفات التي تحمل الأسماء نفسها.
3. **احتفظي بملف `.env` الأصلي الخاص بك ولا ترفعيه إلى GitHub.** لا تنسخي المفتاح داخل أي كود.
4. افتحي Terminal داخل مجلد المشروع واكتبي:

   ```powershell
   npm install
   npm start
   ```

5. افتحي `http://localhost:3000`.
6. اكتبي موضوعًا، اختاري مستوى التفصيل، واضغطي **إنشاء التقرير ومعاينته**. عدّلي النص ثم اختاري الصيغة واضغطي **تحميل التقرير**.

## الملفات ووظائفها

- `server.js`: مسارات إنشاء محتوى التقرير وتصديره، والتحقق من الملفات، والاتصال بـ Gemini.
- `public/index.html`: حقول الواجهة والقوالب والمعاينة.
- `public/script.js`: طلب إنشاء المحتوى، تحرير النص، رفع الصور والتصدير.
- `public/style.css`: مظهر الموقع وتجاوبه مع الجوال.
- `utils/generateDocx.js`: إنشاء Word بالعربية والصور.
- `utils/generatePdf.js`: إنشاء PDF من HTML باستخدام Chrome؛ لتفادي مشاكل RTL في PDFKit.
- `utils/generatePptx.js`: إنشاء PowerPoint مع تقسيم المحتوى الطويل إلى شرائح وإضافة الصور.
- `utils/common.js`: الألوان والأدوات المشتركة.

## تنبيهات مهمة

- **PDF يحتاج متصفح Chrome أو Edge مثبتًا**. إذا لم يُكتشف، حددي `CHROME_PATH` في `.env` إلى مسار ملف `chrome.exe`.
- الصور التلقائية من الإنترنت **غير مفعلة** في هذه النسخة؛ الصور التي ترفعينها تُدرج في الملفات الثلاثة. تجنّبنا إظهار خيار لا ينفّذ ما يعد به.
- تغيير القالب يؤثر في ألوان ملفات التصدير. تغيير مستوى التفصيل يحتاج الضغط على إنشاء التقرير مجددًا.
- معاينة التقرير قابلة للتحرير على مستوى الحقول والفقرات الموجودة، ولا تدعم إضافة أقسام جديدة من الواجهة بعد.
- اختبري تصدير الملفات الثلاثة ومراجعة تنسيقها على جهازك قبل نشر المشروع. جودة المحتوى تعتمد على Gemini وقد تحتاج مراجعة بشرية.
- `.gitignore` يمنع رفع `.env` و`node_modules`، لكن راجعي الملفات قبل أي `git push`.
